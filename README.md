## 🧠 الفكرة

**مدارك جو** منصة تعليمية مجانية انطلقت بجهد طالب من **جيل 2009**، بهدف جمع كل ما يحتاجه الطالب في مكان واحد سهل وسريع.  
نحن نؤمن بأن التعليم الجيد يجب أن يكون متاحاً للجميع دون حواجز مالية أو تقنية.

> "منصة وُلدت من الميدان وتحمل روح المتعلم الحقيقي."

---

## ✨ ما الذي نقدمه؟

| القسم | الوصف |
|-------|-------|
| 📚 **مواد دراسية** | روابط مختارة لشرح مبسط للمواد الأساسية. |
| 📝 **امتحانات وزارية** | نماذج سابقة وامتحانات وزارية منسقة. |
| ⚡ **تحديات السرعة** | مسابقات تفاعلية لاختبار معرفتك. |
| 💬 **دردشة دراسية** | فضاء للأسئلة والاستفسارات بين الطلاب (يُفتح يومياً). |
| 📖 **كتب وزارية** | نسخ إلكترونية للكتب المدرسية. |
| 🎯 **مؤشر الإنجاز** | تتبع تقدمك الدراسي. |

---

## 🛠️ التقنيات المستخدمة

- `HTML5` + `CSS3` (مع تصميم متجاوب وثيم داكن)
- `JavaScript` (عداد تنازلي، تذكر السنة، نافذة iframe)
- **GitHub Pages** – لاستضافة الموقع مجاناً
- **Google Analytics** + **AdSense** – للإحصاءات والدعم المستمر
- **Discord API** – مجتمع الطلاب
